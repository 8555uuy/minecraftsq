本工具使用标准 nbt.js 格式：每个节点为 { "type": "...", "value": ... } 结构，最外层固定为：

{
  "name": "Data",                     // 根标签名称（如 level.dat 为 "Data"）
  "value": {                          // 根 compound
    "levelName": { "type": "string", "value": "我的世界" },
    "GameType":   { "type": "int",    "value": 1 },
    "Time":       { "type": "long",   "value": [0, 12345] },
    "Tags":       { "type": "list",   "value": { "type": "string", "value": ["a", "b"] } },
    "GameRules":  {
      "type": "compound",
      "value": {
        "keepInventory": { "type": "string", "value": "true" }
      }
    }
  }
}

支持的 type：byte / short / int / long / float / double / string / byteArray / intArray / longArray / list / compound。

注意：long 类型在 JavaScript 中无法精确表示 64 位整数，因此用 [高位, 低位] 两个 32 位数字表示。list 的 value 是元素类型节点，即 {"type":"元素类型","value":[元素...]}；元素类型为 compound 时，元素是字段对象数组。
