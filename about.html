关于我们

认识 MC开发者工具箱 —— 一个为我的世界开发者打造的全本地在线工具集合。

🧰 我们是谁

MC开发者工具箱是一个面向我的世界（Minecraft）Java 版开发者的在线工具集合网站。我们致力于把数据包开发、存档分析、指令调试中常见的重复性工作整理成简单易用的网页工具，让开发者可以快速完成 NBT 与 JSON 互相转换、数据包 zip 批量校验、mcfunction 格式化与语法检查等工作，从而把精力更多地放在创作本身。

🎯 项目用途与开发目的

在数据包与存档开发过程中，开发者常常需要在 NBT、JSON、指令三种格式之间反复切换，还要面对"哪里写错了导致数据包加载失败"这类难以排查的问题。市面上的同类工具往往依赖服务器上传处理，开发者会担心自己的存档数据安全。

因此我们开发这个项目，目的是：

  • 为中文 MC 开发者提供一套免费、无门槛、无需注册的常用工具。
  • 坚持全部功能在浏览器本地运行，用户的存档、数据包文件只在本机内存中处理，从技术上杜绝文件外泄的可能。
  • 持续补充数据包开发中高频使用的辅助功能，帮助新手快速上手，帮助老手提升效率。

⚙️ 技术实现

本网站是纯前端静态网站，采用 HTML + TailwindCSS + 原生 JavaScript 构建，并在浏览器端引入 JSZip（zip 解压）与 nbt.js（NBT 解析）等开源库。整站没有后端服务器，所有文件读取、解析、格式化、校验均由你的浏览器本地完成，双击 HTML 文件即可离线使用全部功能。

📦 当前功能

  • NBT 转换工具：上传 .nbt / .dat 存档文件，NBT ↔ JSON 互相转换，支持 gzip 压缩 Java 版 NBT，JSON 语法高亮，中文错误提示。
  • 数据包批量校验：上传数据包 zip，浏览器自动解压扫描 JSON 语法、命名空间、目录结构与 mcfunction 常见错误，输出中文错误清单。
  • MCFunction 格式化：粘贴指令代码，一键格式化排版、简单语法错误检测，导出下载 .mcfunction 文件。
  • Mod 模组汉化翻译：正在开发中，敬请期待。

🔒 隐私承诺

我们始终把用户数据安全放在第一位：本网站不注册账号、没有后端、不收集任何用户文件，你上传或粘贴的所有内容只会停留在你自己的浏览器中，关闭页面即自动销毁。详细说明请查看隐私政策。
